# 🌟 About The Project

**Aruna Game Hub** is an interactive web-based platform that combines multiple mini-games, productivity tools, utilities and personal web applications into one centralized dashboard.

The project starts with a **Login System**, where the user enters their name, email and password. After login, the user is redirected to an animated **Game Hub Dashboard** containing multiple applications.

Instead of opening different websites for different tasks, Aruna Game Hub brings everything together into one interactive interface.

> 💡 **One Dashboard. Multiple Games. Multiple Tools. One Web Application.**
